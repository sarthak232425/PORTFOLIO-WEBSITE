Car Controller

High-Fidelity 3D Vehicle Dynamics & Physics Engine

> System_Overview

Realistic Car Controller (RCC) is a modular, high-fidelity vehicle simulation framework developed from the ground up in Unity 3D and C#. Designed specifically for publishing on the Unity Asset Store, it provides developers with plug-and-play vehicle kinematics, real-time telemetry, and modular mechanical tuning.

Rather than relying on basic arcade velocity manipulation, the controller models authentic tire friction slips (Pacejka model approximations), engine RPM torque curves, automatic and manual gear transmission with clutch simulation, and dynamic weight transfer over variable suspensions.

> Core_Mechanics & Architecture

  • Engine Torque Curves & Drivetrain Simulation

    Engineered an engine torque curve system using AnimationCurve in Unity to model real engine output, horsepower transfer, and automatic gear-shifting points with customizable redlines and gear ratios.

  • Drift Mechanics & Wheel Friction Curves

    Fine-tuned Unity's WheelCollider forward and sideways friction stiffness curves dynamically based on handbrake inputs, downforce, and slip angles, allowing smooth transitions between high-grip circuit racing and high-angle drifting.

  • Dynamic Dashboard Telemetry & Layered Audio

    Built analog speedometer/tachometer needles with rotational interpolation, gear shift indicators, and a layered audio synthesis engine with pitch-modulated engine sound, turbo blow-off valves, and tire skid squeals.

// Vehicle Drivetrain & Gear Shifting Simulation (Unity C#)
private void CalculateRPM() {
    float wheelRPM = Mathf.Abs((wheelFL.rpm + wheelFR.rpm) / 2f);
    targetRPM = Mathf.Lerp(minRPM, maxRPM, (wheelRPM * gearRatios[currentGear]) / maxSpeed);
    currentRPM = Mathf.MoveTowards(currentRPM, targetRPM, engineResponsiveness * Time.deltaTime);

    if (isAutomaticTransmission) {
        if (currentRPM >= upshiftRPM && currentGear < gearRatios.Length - 1) {
            ShiftGear(currentGear + 1);
        } else if (currentRPM <= downshiftRPM && currentGear > 0) {
            ShiftGear(currentGear - 1);
        }
    }
}
