Block Blocker

Glitched 2025 GameJam Champion • 2D Arcade

> System_Overview

Block Blocker is a fast-paced 2D arcade game built during the Glitched 2025 GameJam. The core objective was to create a highly addictive, infinitely scaling gameplay loop with minimal assets but maximum polish.

> Core_Mechanics

  • Dynamic Difficulty Algorithm: Engineered a custom C# script that adjusts spawn rates and obstacle velocity based on the player's survival time, ensuring a smooth flow state curve.
  • Event-Driven Architecture: Utilized C# Actions and Events to decouple the UI system from the core game loop, making the codebase scalable and bug-free during the rapid jam environment.
  • Optimized Physics: Relying on Unity's Rigidbody2D and optimized BoxColliders to ensure 60FPS performance even when dozens of blocks are spawned on screen.
