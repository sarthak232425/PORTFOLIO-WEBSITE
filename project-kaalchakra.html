KaalChakra

Physics-Driven 2D Platformer with Modular System Architecture

> System_Overview

KaalChakra is a flagship collaborative 2D game engineered in partnership between GameDevUtopia and Pictorial at the Pune Institute of Computer Technology (PICT).

As core developer and Ex-Coding Head, I architected the fundamental gameplay prototype, rigid-body player controller kinematics, customizable input rebinding mechanisms, and the complete audio and volume management infrastructure.

> Core_Mechanics & Architecture

  • Scalable & Remappable Input Systems

    Developed an abstraction layer on top of Unity's input system, enabling seamless keyboard and gamepad remapping, dynamic deadzone calibration, and persistent user configuration across game restarts.

  • Modular Audio Mixer Subsystem

    Integrated Unity's AudioMixer groups with logarithmic decibel conversion equations, allowing independent master, ambient soundtrack, and SFX volume channels that respond immediately to UI sliders.

  • Precision 2D Rigid Body Kinematics

    Engineered custom ground-checking raycasts, variable jump height modulation based on button hold duration, and coyote time jump buffers for tight, responsive platforming.
