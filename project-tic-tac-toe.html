Tic Tac Toe Ultimate

Minimalist UI-Driven Game Engineered Entirely with Unity Canvas & C# State Logic

> System_Overview

Tic Tac Toe Ultimate is an exploration into pushing Unity's native UI system (UGUI) to its full potential as a complete, self-contained game framework.

Rather than using standard scene objects or 3D meshes, every interactive element—from the board cells, animated turn indicators, win-condition matrix validators, to modal popups—was built as a modular UI component driven by a robust finite state machine in C#.

> Core_Mechanics & Architecture

  • Finite State Machine (FSM) Game Loop

    Built a structured FSM managing discrete states: MainMenu, PlayerTurn, EvaluatingBoard, RoundWin, and DrawReset, preventing illegal concurrent inputs or race conditions.

  • Algorithmic Win-Condition Matrix Validator

    Implemented bitmask and matrix traversal algorithms in C# to calculate diagonal, horizontal, and vertical 3-in-a-row connections with microsecond execution times.

  • Responsive Canvas Anchoring & Minimalist UI

    Engineered responsive UI anchoring with custom auto-layout groups and tweened canvas groups that scale seamlessly across 16:9, 18:9, and ultra-wide aspect ratios without text distortion.

// Win-Condition Checker Algorithm (Unity C#)
private readonly int[][] winCombos = new int[][] {
    new int[] {0,1,2}, new int[] {3,4,5}, new int[] {6,7,8}, // Rows
    new int[] {0,3,6}, new int[] {1,4,7}, new int[] {2,5,8}, // Cols
    new int[] {0,4,8}, new int[] {2,4,6}                    // Diagonals
};

public bool CheckForWinner(CellState mark) {
    foreach (var combo in winCombos) {
        if (board[combo[0]] == mark && board[combo[1]] == mark && board[combo[2]] == mark) {
            TriggerWinSequence(combo, mark);
            return true;
        }
    }
    return false;
}
